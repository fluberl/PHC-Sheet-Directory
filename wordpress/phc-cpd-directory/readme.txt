Embeds the PHC Schweiz CPD directory with the shortcode [phc_cpd_directory].

Shortcode:

[phc_cpd_directory]

Outputs exactly:

<div id="phc-cpd-directory"></div>

CSS and JavaScript load only on pages that render this shortcode.
