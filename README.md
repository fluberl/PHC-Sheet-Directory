# PHC Sheet Directory

A reusable directory engine for publishing structured data from Google Sheets to WordPress.

## Initial implementation

- PHC Schweiz Member Directory

## Planned implementations

- Member Directory
- CPD Directory
- Events Directory
- Provider Directory

## Principles

- Google Sheets as Single Source of Truth
- HTML/CSS/JavaScript frontend
- Easy embedding into Thrive Architect
- Reusable across multiple organizations
